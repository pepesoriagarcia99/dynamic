# Dynamic

Una suite de componentes configurables mediante JSON que permite crear interfaces de usuario sin necesidad de programar.

## ¿Qué es?

Dynamic es una librería que proporciona componentes listos para usar (como tablas y formularios) que se configuran completamente mediante objetos JSON. No necesitas escribir código para personalizar su comportamiento o apariencia.

## ¿Cómo funciona?

Puedes usar las configuraciones JSON de dos formas:

- **Integración directa**: Pasa las configuraciones como propiedades de los componentes en tu aplicación
- **Configuración dinámica**: Almacena las configuraciones en una base de datos para modificar el comportamiento de tu aplicación sin tocar el código

## Estructura del proyecto

- **FRONTEND**: Web componentes configurables
- **BACKEND**: API y servicios de soporte

Consulta los README específicos en cada carpeta para más detalles técnicos.
